# Bearite

Неофициальный лаунчер для **Super Bear Adventure** с модами и своими картами. Оригинальная игра остаётся нетронутой: Bearite запускает её у себя и добавляет код модов.

- Скачать лаунчер: [Bearite-debug.apk](https://github.com/Sp1KLe/Bearite/releases/download/latest/Bearite-debug.apk) (заменяется при каждой сборке на `main`).
- Скачать приложение для отправки модов на сервер: [Bearite-Mods.apk](https://github.com/Sp1KLe/Bearite/releases/download/latest/Bearite-Mods.apk).
- Нужна установленная игра из Google Play (проверено на версии 13.0.8) и телефон с arm64.

## Лаунчер коротко

1. Установи APK, открой Bearite: на вкладке **Игра** должна гореть «Super Bear Adventure найдена».
2. **Играть** запускает игру с модами. Кнопка **Загрузить сохранение (.sba)** на той же вкладке подменяет сохранение игры (файл копируется как есть в `Android/data/com.bearite.patcher/files`, с тем же именем и расширением).
3. На паузе в игре появляется кнопка **Меню**: вкладка **Установлено** (все твои моды, выключенные полупрозрачные), **Все моды** (каталог с сервера, установка одной кнопкой), а также карты и мини-игры.
4. Вкладка **Лог** показывает, что происходит внутри; кнопка «Копировать» нужна, чтобы прислать лог при ошибке.

## Как сделать мод через GitHub

Компьютер и Android NDK не нужны: мод собирает GitHub в облаке, всё делается в браузере телефона.

### 1. Свой репозиторий

1. Зарегистрируйся на github.com (бесплатно).
2. Открой этот репозиторий и нажми **Fork** → **Create fork**. Теперь у тебя своя копия.
3. В своей копии открой вкладку **Actions** и, если спросит, разреши запуск воркфлоу (**I understand my workflows, go ahead and enable them**).

### 2. Папка мода

В своей копии создай папку `sdk/mods/мой-мод/` (на телефоне: **Add file → Create new file**, в имени файла можно писать `/`, и папки создадутся сами). В ней должны быть два файла:

```
sdk/mods/мой-мод/
├── mod.json        описание мода
├── src/mod.c       код мода на C
└── icon.png        (необязательно) аватарка, квадрат 128–256 px
```

Проще всего скопировать готовое из `sdk/mods/template/`: открой файл, нажми «Copy raw file» и вставь в новый.

**mod.json**

```json
{
  "id": "my-mod",
  "name": "Мой мод",
  "version": "1.0",
  "author": "я",
  "description": "Что делает мод",
  "libs": ["libs/arm64-v8a/libmymod.so"],
  "settings": [
    { "id": "speed", "type": "float", "name": "Скорость", "min": 0.5, "max": 3, "default": 1, "control": "slider" }
  ],
  "hud": [
    { "label": "+", "setting": "speed", "action": "step", "step": 0.5, "pos": "right" }
  ]
}
```

| Поле | Что значит |
|---|---|
| `id` | Обязательно. Латиница, цифры, `_`, `-`, `.`. По нему хранятся настройки; мод с тем же `id` при установке заменяется |
| `name`, `version`, `author`, `description` | Показываются на карточке мода |
| `libs` | Куда сборка положит скомпилированную библиотеку, например `libs/arm64-v8a/libmymod.so` (имя любое, но в формате `lib<имя>.so`; только arm64-v8a) |
| `settings` | Настройки, рисуются в меню сами |
| `hud` | Кнопки прямо на экране игры, меняют настройки |

Типы настроек: `bool` (переключатель), `int` и `float` (кнопки «−/+» или ползунок при `"control": "slider"`, нужны `min` и `max`), `string` (поле), `choice` (список из `options`).
Действия кнопок `hud`: `toggle` (для `bool`), `step` (прибавляет `step` к числу), `cycle` (листает `choice`); `pos` — `left` или `right`.

**src/mod.c**

```c
#include "bearite_api.h"
#include "bearite_il2cpp.h"

__attribute__((visibility("default")))
void bearite_mod_init(const BeariteApi* api, const char* mod_id) {
    api->log(mod_id, "Привет из мода!");                  /* строка попадёт во вкладку «Лог» */
    double speed = api->get_float(mod_id, "speed", 1.0);  /* значение из настроек, обновляется на лету */
}
```

Через `api` доступны: `log`, `get_bool / get_int / get_float / get_string` (настройки), `data_dir` (папка для своих файлов), `hook` и `il2cpp_symbol` (низкоуровневые хуки). Полный список с комментариями: `sdk/bearite_api.h`.

**Перехват метода игры по имени** (самое частое, что нужно моду):

```c
static void (*orig)(void* self, float value, const void* method);

static void my_hook(void* self, float value, const void* method) {
    orig(self, value / 2.0f, method);            /* свой код, потом оригинал */
}

void bearite_mod_init(const BeariteApi* api, const char* mod_id) {
    if (!bearite_il2cpp_init(api)) return;
    bearite_hook_method(api, mod_id, "UnityEngine", "Camera", "set_fieldOfView", 1,
                        (void*)my_hook, (void**)&orig);
}
```

Для метода экземпляра первым аргументом идёт `self`, последним всегда `const void* method`. Имена классов и методов игры можно узнать дампером IL2CPP (например Il2CppDumper). Готовый пример побольше: `sdk/sba-zoom/` (мод «Зум»). Подробности и другие помощники: `sdk/README.md`.

### 3. Сборка

Нажми **Commit changes**. GitHub Actions сам соберёт все моды из `sdk/mods/`. Следи на вкладке **Actions**: зелёная галочка значит готово.
Ошибка компиляции показана красной строкой в запуске (раздел **Annotations**) и в логе шага «Build mods from sdk/mods».

### 4. Забрать мод

Actions → последний запуск → внизу **Artifacts** → `Bearite-mods` (скачается zip, в нём лежит `<id>.zip` твоего мода). Внешний архив распакуй: ставить нужно именно **внутренний** `<id>.zip`.

### 5. Поставить и проверить

- **Себе:** Bearite → вкладка **Моды** → **Установить мод** → выбери `<id>.zip`.
- **Всем:** установи приложение [Bearite-Mods.apk](https://github.com/Sp1KLe/Bearite/releases/download/latest/Bearite-Mods.apk), один раз вставь в него токен GitHub и нажми **Отправить мод (.zip)**. Мод появится у всех во вкладке «Все моды» (**Обновить**), без переустановки игры.
  Токен: GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token; Repository access — только твой репозиторий, Permissions → Contents: **Read and write**. Токен хранится только в твоём приложении. Моды лежат в релизе `user-mods` репозитория, проверки нет.
- Мод **с** `libs` выключен, пока его не включат в «Установлено» и не подтвердят предупреждение про нативный код. Мод без `libs` включён сразу.
- Новая версия: подними `version` в `mod.json`, собери и поставь поверх; настройки пользователя сохранятся.

### Если не работает

| Что видно | Что делать |
|---|---|
| Сборка красная | Читай красную строку в Annotations: обычно опечатка в `mod.c` или в `libs` |
| Мод не появился в списке | В `mod.json` ошибка (нет `id`, лишняя запятая). Причина написана во вкладке «Лог» |
| Мод есть, но ничего не делает | Он выключен или не подтверждён. Смотри строки `мод …` в «Лог» после запуска игры |
| Хук не сработал | В «Лог» будет `перехват …: не найден`: проверь пространство имён, класс, метод и число аргументов |
| Игра вылетела | При следующем открытии Bearite сам добавит в лог строки из logcat про аварию; скопируй их |

## Ещё немного

- **Карты.** Вкладка «Карты» в меню на паузе: редактор своих карт из примитивов, импорт из буфера (`BEARITE-MAP`), свой мир со своим названием и обложкой, круг-вход в игровом стиле.
- **Мини-игры.** В меню на паузе: паркур-гонка, царь горы и догонялки на специальных аренах. Запускает хост комнаты; вкладка «Мультиплеер» в меню задаёт лимит игроков при создании комнаты.
- **Чат.** Кнопка 💬 поверх игры, работает в комнате мультиплеера (общий публичный ntfy.sh); окно двигается и меняется в размере.

## Сборка из исходников

Любой пуш в `main` собирает APK через GitHub Actions (`.github/workflows/build.yml`) и обновляет релиз `latest`; моды из `sdk/mods/` собираются там же и публикуются в каталог. Локально нужны Android Studio / Gradle 8.5, NDK 26.1 и CMake 3.22, а перед первой сборкой `scripts/build_dobby.sh` (хуки).

Устройство лаунчера: `GameActivity` в отдельном процессе `:game` собирает загрузчик классов из APK игры и запускает Unity; нативная `libbearite.so` ждёт IL2CPP и подключает моды, встроенный мод `libbearite_mod.so` отвечает за карты, мини-игры и окно уровня.
